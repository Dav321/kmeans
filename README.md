# K-Means Clustering Visualization

A real-time interactive visualization of the K-means clustering algorithm built with Rust and ggez.

## Controls

- **Left Click**: Add a new data point
- **Middle Click**: Add a new cluster center (K)
- **Right Click**: Remove nearest point or cluster center
- **Enter**: Run one iteration of the K-means algorithm
- **R**: Generate 100 random points with 6 random cluster centers
- **Backspace**: Clear all points and cluster centers
- **Escape**: Quit the application
